# Rotten-Tomatoes-Sentiment-Analysis-LSTM


#  Movie Review Sentiment Analysis Using LSTM

## Introduction

This project presents a Deep Learning-based approach for sentiment analysis of movie reviews using Long Short-Term Memory (LSTM) networks. The objective is to automatically classify movie reviews as **Positive** or **Negative** by leveraging Natural Language Processing (NLP) techniques and sequential neural networks.

## Project Objectives

* Analyze textual movie reviews and identify sentiment.
* Apply text preprocessing and feature preparation techniques.
* Build and train an LSTM-based neural network.
* Evaluate model performance on unseen data.
* Predict sentiment for custom user reviews.

## Dataset

The project utilizes the **Rotten Tomatoes Movie Reviews Dataset**, which contains a large collection of movie reviews labeled according to their sentiment. The dataset is used to train and evaluate the model's ability to understand and classify review text.

## Methodology

The following steps were performed during the project:

1. Data Collection and Loading
2. Data Cleaning and Preprocessing
3. Text Tokenization
4. Sequence Padding
5. Train-Test Data Splitting
6. LSTM Model Development
7. Model Training and Validation
8. Performance Evaluation
9. Sentiment Prediction

## Technologies and Tools

* Python
* TensorFlow / Keras
* NumPy
* Pandas
* Scikit-learn
* Matplotlib
* Natural Language Processing (NLP)

## Model Architecture

* Embedding Layer
* LSTM Layer
* Dense Layer
* Dropout Layer
* Sigmoid Output Layer

## Results

The trained LSTM model successfully learns sentiment patterns from movie reviews and performs binary sentiment classification. The model is capable of predicting whether a review expresses a positive or negative opinion with high accuracy.

## Conclusion

This project demonstrates the effectiveness of LSTM networks for sentiment analysis tasks. By combining NLP preprocessing techniques with deep learning, the model can accurately classify movie reviews and provide valuable insights from textual data.
